# Alibarbar Ingot 9000 vs Gunnpod

| Feature | Alibarbar Ingot 9000 | Gunnpod |
|---------|---------------------|---------|
| Puff count | Up to 9000 | ~2,000 (classic) |
| E-liquid | 22ml | ~8–13ml |
| Battery | 2350mAh | Varies |
| Display | Smart LED | Most: none |
| Size | ~90g | More compact |

**Verdict:** Ingot 9000 offers ~4× the classic Gunnpod puff capacity. Gunnpod suits pocket-friendly preference.
