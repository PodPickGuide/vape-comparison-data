# Alibarbar Ingot 9000 vs RELX

| Feature | Alibarbar Ingot 9000 | RELX |
|---------|---------------------|------|
| Format | All-in-one disposable | Rechargeable pod system |
| Puffs | Up to 9000 per device | Depends on pods |
| Charging | Non-rechargeable | **Rechargeable** |
| Coil | Built-in sealed | Replaceable pods |
| Setup | None — out of box | Charge + insert pods |
| Display | Smart LED | Model-dependent |

**Verdict:** Different formats. Alibarbar = maximum simplicity. RELX = reusable device + pod swapping.
